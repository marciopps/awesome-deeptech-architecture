# Contributing to Awesome DeepTech Architecture & Ontology

Thank you for your interest in contributing to the **Awesome DeepTech Architecture Portfolio & Ontology**.

## Scope of Contributions
We welcome contributions that expand, refine, and verify technical specifications across our 32 industrial deep-tech verticals:
- Additions of emerging engineering standards (NIST, IEEE, 3GPP, AUTOSAR, IETF RFCs).
- Architectural whitepapers, benchmark data, and formal specification diagrams.
- Errata or updates to technical taxonomies and category classifications.

## Guidelines
1. **Technical Rigor**: All additions must reference authoritative specifications, RFCs, or peer-reviewed research.
2. **Neutral Format**: Maintain the structured catalog schema (Domain, Tier, Cluster, Wayback verification).
3. **English as Master Key**: In line with the ecosystem specification, all primary technical definitions must be submitted in English.

## Submitting Pull Requests
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/topic-refinement`).
3. Commit your changes with descriptive messages (`git commit -m "docs(pqc): update FIPS 203 NTT vector notes"`).
4. Push to the branch (`git push origin feature/topic-refinement`).
5. Open a Pull Request.
